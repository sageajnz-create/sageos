## Limitations

1. **Layered package.** `grokbot-linux-port` is layered with rpm-ostree, which makes the booted
   deployment bootc-incompatible. This run is therefore not a pristine bootc-managed deployment.
2. **Unverified image origin.** Origin is `ostree-unverified-registry:` and doctor reports
   `signature policy does not require sigstore (/etc/containers/policy.json)`. Signature verification
   is not being enforced on metal.
3. **Doctor workaround.** See collection caveat above; doctor output is not from the shipped recipe.
4. **Not captured.** CPU model (`/proc/cpuinfo`), RAM, drive inventory, monitors
   (resolution/refresh/VRR/HDR), and peripherals.
